# Mobile Product Radar | 移动产品雷达

面向独立移动开发者的每日创业情报库。关注真实需求、成熟游戏玩法、增长趋势、商业化与跨平台机会。

## 归档

- `daily/YYYY-MM-DD.md`：每日五分钟简报
- `data/YYYY-MM-DD.json`：结构化产品情报
- `weekly/`：每周候选产品复盘（预留）
- `opportunities/`：产品机会分析（预留）

## 数据来源

App Store、Google Play、HarmonyOS、Reddit、Hugging Face、Product Hunt、GitHub Trending、Google Trends、TikTok Creative Center、Meta Ads Library 等公开来源。

## 原则

以可验证的排名、增长、用户反馈及商业信号为依据；标注日期、地区、来源与数据限制。区分事实、估算和判断，不虚构下载量或收入。优先成熟需求、低成本验证、自然获客和可持续变现。

仓库保持私有。每日归档由 ChatGPT 定时任务执行，不依赖仓库内的 GitHub Actions。
